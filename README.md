## Purpose
Discord Bot that implements Google Translate API to translate messages sent in Discord to a selected language (or languages). Also used Google Sheets API to call on a spreadsheet that contained various Spanish or Korean (depending on user choice) terms, which were selected and prompted the user to respond with their meanings in English. A fun project created to enhance a user's language-learning experience via Discord.
